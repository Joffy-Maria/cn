Berkeley Sockets C API Lifecycle (TCP vs UDP)

Compare system call sequence between Connection-Oriented TCP and Connectionless UDP

TCP Stream Sockets (SOCK_STREAM) Reliable
1. socket(AF_INET, SOCK_STREAM, 0) ➔ Create endpoint
2. bind(sockfd, (struct sockaddr*)&addr, len) ➔ Bind IP & Port
3. listen(sockfd, backlog) ➔ Transition to passive listener
4. accept(sockfd, &cli, &len) ➔ Block until 3-way handshake done
5. send() / recv() or read() / write() ➔ Exchange stream bytes
6. close() ➔ Send FIN packet for 4-way disconnect
UDP Datagram Sockets (SOCK_DGRAM) Connectionless
1. socket(AF_INET, SOCK_DGRAM, 0) ➔ Create datagram socket
2. bind(sockfd, (struct sockaddr*)&addr, len) ➔ Server binds port
❌ No listen() or accept() required!
3. recvfrom(sockfd, buf, len, 0, &src, &len) ➔ Receive msg + sender addr
4. sendto(sockfd, buf, len, 0, &dest, len) ➔ Send independent packet
5. close() ➔ Release local descriptor
